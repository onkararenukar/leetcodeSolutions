## 🎯 Study Strategy

### Phase 1: Foundation (Weeks 1-4)
- Focus on easy problems
- Build problem-solving muscle
- Learn basic patterns

### Phase 2: Core Skills (Weeks 5-8)
- Mix of easy and medium
- Focus on common patterns
- Time yourself

### Phase 3: Advanced (Weeks 9-12)
- Mostly medium problems
- Some hard problems
- Optimize solutions

### Phase 4: Mastery (Weeks 13-24)
- All difficulty levels
- Focus on weak areas
- Mock interviews

## 💡 Tips for Using This Mapping

1. **Start with easy problems** in each topic
2. **Progress to medium** once comfortable
3. **Attempt hard problems** for deep understanding
4. **Track your progress** using the checklist
5. **Revisit problems** you struggled with
6. **Focus on patterns** rather than memorization
7. **Time yourself** to build speed
8. **Review solutions** to learn optimizations
